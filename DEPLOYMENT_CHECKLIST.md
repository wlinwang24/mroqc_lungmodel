# Predeployment sign-off checklist

- [ ] Matt approves the exact model versions in `fg_model_specs.R` and `model_copd_clinical_only.rds`.
- [ ] MROQC data owner authorizes publishing/storing model RDS and dose-support summary; review embedded training data and residuals.
- [ ] Research/privacy team approves Google Analytics collection on the new host or removes the script.
- [ ] All five expected endpoints work: Any Lung, Pneumonitis, Pneumonia, COPD, Any Cardiac. G2+ and G3+ Esophagitis appear only in the eligible 30-fraction setting.
- [ ] For fixed synthetic inputs, predictions agree between the approved legacy build and the Connect Cloud candidate (allow only defined numeric tolerance).
- [ ] `manifest.json` generated by `rsconnect::writeManifest()` in RStudio.
- [ ] Fresh repository created, without old Git history or analysis workspaces; branch and owners agreed.
- [ ] Connect Cloud test deployment succeeds on institution-managed account.
- [ ] Concurrent sessions tested with distinct inputs and acceptable latency.
- [ ] Domain owner identified; wildcard or single-subdomain DNS setup verified with SPH IT.
- [ ] App URL and HTTPS verified; sharing access configured appropriately.
- [ ] Maintenance runbook with Maggie / IT and rollback path agreed.
- [ ] Review responsive Summary visual layout at portrait phone sizes (e.g. 320/375/430 px) and desktop (>=1200 px); confirm 2-by-2 mobile bars, legible labels and 15px time note, no overlap or clipping.
- [ ] Confirm the two mobile plot groups share identical y-axis limits and their percentages match the desktop Summary for identical inputs.
